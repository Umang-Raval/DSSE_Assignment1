**Overview**
----------------

This Java class, `PriorityUtilizationQueueOrderingPolicy`, is a key component within the Hadoop YARN Resource Manager's Scheduling/Resource Management layer. It is responsible for determining the optimal ordering of resource queues based on a combination of priority, utilization, and accessibility constraints, ensuring efficient resource assignment.

**Key Characteristics**
-------------------------

* **Architectural Role**: Scheduling/Resource Management Component
* **Primary Functionality**: Orders queues for resource allocation considering:
	1. **Priority** (configurable, via `respectPriority`)
	2. **Utilization** (relative assigned capacity)
	3. **Accessibility** to node labels/partitions
	4. **Configured Minimum Resources** and **Absolute Capacity** as tie-breakers
* **Core Logic**:
	+ Custom `compare` method for queue comparison
	+ `PriorityQueueComparator` for multi-factor queue sorting
* **Interfaces**:

		- Node label/partition (`String`) for accessibility checks
		- `respectPriority` flag (set via constructor)
	+ **Outputs**:
		- Ordered `Iterator<CSQueue>` for resource assignment
