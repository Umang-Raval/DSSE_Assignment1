**File Summary: Queue Preemption Settings Component**

**Overview**
----------------

This Java component, part of the Capacity Scheduler's Resource Manager (YARN), resides within the Configuration/Policy layer. It plays a crucial role in determining preemption settings for queues within a hierarchical structure, influencing scheduling decisions.

**Key Responsibilities**
-------------------------

* Evaluates system-wide and queue-specific configurations to determine:
	+ Cross-queue preemption settings
	+ Intra-queue preemption settings within the queue hierarchy
* Provides preemption status outputs for a given queue, impacting scheduler decisions

**Technical Details**
----------------------

* **Input Parameters:**
	+ `CSQueue` object (target queue for evaluation)
	+ `CapacitySchedulerConfiguration` object (containing system-wide and queue-specific settings)
* **Output Values:**
	+ `preemptionDisabled`: Boolean indicating overall preemption status
	+ `intraQueuePreemptionDisabledInHierarchy`: Boolean for intra-queue preemption within the hierarchy
* **Core Logic:**
	+ Recursive traversal of the queue hierarchy via `isQueueHierarchyPreemptionDisabled()` and `isIntraQueueHierarchyPreemptionDisabled()` methods, considering system-wide switches and explicit overrides
* **Dependencies:**
	+ `org.apache.hadoop.yarn.conf.YarnConfiguration`
	+ `org.apache.hadoop.yarn.server.resourcemanager.scheduler.capacity.CapacitySchedulerConfiguration`
	+ `org.apache.hadoop.yarn.server.resourcemanager.scheduler.capacity.CSQueue`
* **Scheduler Interactions:**
	+ Consumes: Capacity Scheduler Configuration and Queue Hierarchy (`CSQueue` objects)
	+ Influences: Scheduling decisions through provided preemption settings for queues
