**Overview**
----------------

The `ParentQueue` class, extending `AbstractParentQueue`, resides in the **Business Logic Layer** of the Capacity Scheduler and Resource Manager (YARN) subsystem. It dynamically manages child queues within a capacity-scheduled YARN cluster, enforcing queue limits, capacity configurations, and resource updates.

**Key Responsibilities**
-------------------------

* Dynamically creates leaf or parent child queues while ensuring consistency with existing queues, max queue limits, and capacity configurations.
* Updates internal state and recalculates cluster resources upon successful child queue additions.
* Interacts with other scheduler components to retrieve queues, update cluster resources, and fetch configuration settings.
