**File Summary: ManagedParentQueue Implementation**

**Overview**
----------------

This Java file implements the `ManagedParentQueue` component, a crucial part of the YARN (Yet Another Resource Negotiator) Resource Manager's Scheduler layer, specifically designed for the Capacity Scheduler. It dynamically manages a parent queue, auto-creating leaf queues based on predefined templates and policies while enforcing capacity constraints and validating configurations.

**Key Responsibilities**
-----------------------------

1. **Dynamic Leaf Queue Management**: Auto-creates `AutoCreatedLeafQueue` instances under a parent queue, adhering to predefined templates and policies.
2. **Capacity Enforcement & Validation**: Ensures queue configurations comply with set capacities and resource quotas, validating changes before application.
3. **Asynchronous Policy Application**: Applies queue management policy changes, updating queue capacities and reinitializing affected queues.

**Core Functionalities**
--------------------------------

* Initializes leaf queue templates with specified capacities and resource quotas.
* Reinitializes the parent queue upon configuration changes, validating and applying updated queue management policies.
* Updates queue capacities based on absolute resource configurations.
* Validates and adds child queues, confirming they are instances of `AutoCreatedLeafQueue`.
* Manages addition of child queues, checking parent queue existence, capacity limits, and validating guaranteed capacity.
* Applies queue management changes asynchronously, locking writes, validating updates, and committing changes to policy.

---------------------------------------------------

* **Inputs**:
	+ `CapacitySchedulerQueueContext`
	+ `CSQueue` objects (parent and child queues)

	+ `childQueue` for addition
	+ `queueManagementChanges` for policy updates
* **Outputs**:
