**File Summary: `CSQueueStore.java`**

**Overview**
----------------

The `CSQueueStore` component serves as the central repository within the Resource Manager subsystem of Apache Hadoop YARN, specifically designed for managing Capacity Scheduler (CS) queues. It handles queue lifecycle operations (additions, removals, and lookups) while resolving name ambiguities for non-protected queues.

**Key Responsibilities**
-----------------------------

* **Queue Management**: Stores, retrieves, and manages a collection of `CSQueue` objects.
* **Ambiguity Resolution**: Resolves short name ambiguities (excluding the protected "root" queue) using a secondary mapping system.
* **Thread Safety**: Employs `ReentrantReadWriteLock` for concurrency control during modifications.

**Technical Details**
----------------------

* **Data Structures**:
	+ `fullNameQueues` (primary map): `CSQueue` objects keyed by full names.
	+ `shortNameToLongNames` (secondary map): Tracks short to full name mappings for ambiguity resolution.
	+ `getMap` (tertiary cache map): Enhances lookup efficiency by short or full names.
* **Dependencies**:
	+ `VisibleForTesting` (Apache Hadoop)
	+ Google Guava (`ImmutableList`, `ImmutableMap`)
	+ Java Util (`HashMap`, `HashSet`, `ReadWriteLock`)
	+ `CapacitySchedulerConfiguration` (for constants like "ROOT")
* **Interoperability**:
	+ Closely interacts with the Capacity Scheduler to provide managed queues and facilitate queue operations.
	+ Potentially integrates with other Resource Manager components for comprehensive resource management within YARN.

**Input/Output Operations**
--------------------------------

* **Inputs**:
	- `CSQueue` objects for addition
	- Full or short names for retrieval and removal
* **Outputs**:
	- Retrieved `CSQueue` objects by full or short names
	- Ambiguity indicators for given short names
	- Collections of `CSQueue` objects (e.g., all queues)
