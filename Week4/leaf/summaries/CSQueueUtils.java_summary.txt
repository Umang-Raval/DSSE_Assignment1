Utility class for Hadoop YARN's Capacity Scheduler (CS), serving as a Queue Capacity Calculator/Updater within the Resource Management layer.

**Key Functionality:**

* Calculates absolute maximum capacities for queues based on parent queue capacities, node labels, and resource usage
* Updates used capacity, reserved capacity, available resources, and statistics for queues
* Handles both legacy and non-legacy queue modes for capacity calculations
* Integrates with configuration settings for labeled and non-labeled queue capacities

* `updateUsedCapacity`: Updates used and reserved capacities based on resource usage and guaranteed resources
* `updateQueueStatistics`: Refreshes queue statistics (used capacity, absolute used capacity, max available resources) for all or a specific node label partition
