**Overview**
----------------

The `ResourceVector` class serves as a data structure/utility class, representing a collection of resources with floating-point values, grouped by resource names. It supports various operations for managing resource quantities, facilitating efficient resource allocation and scheduling decisions within the Hadoop YARN ecosystem.

* **Data Structure:** Utilizes a `resourcesByName` map to store resource names as keys and their corresponding double values.
* **Core Operations:**

	+ Offers factory methods for initializing `ResourceVector` instances with predefined resource types and values.
* **Input/Output:**
