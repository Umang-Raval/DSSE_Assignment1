**Overview**
----------------

The `MappingRuleCreator` component, situated within the Resource Management layer (specifically, YARN Resource Manager), is responsible for parsing and creating mapping rules that dictate application/user/group to queue mappings for resource allocation in a distributed computing environment (e.g., Hadoop YARN).

**Key Responsibilities**
-------------------------

* **Input Handling**: Parses JSON files or strings containing placement rules.
* **Rule Creation**: Constructs `MappingRule` objects defining application/user/group to queue mappings.
* **Core Logic**:
	+ Deserializes JSON into `MappingRulesDescription`.
	+ Creates `MappingRuleMatcher` based on rule types (USER, GROUP, APPLICATION) and match criteria.
	+ Determines `MappingRuleAction` based on policies (e.g., DEFAULT_QUEUE, REJECT, PRIMARY_GROUP).
	+ Configures fallback behaviors for each `MappingRuleAction`.
