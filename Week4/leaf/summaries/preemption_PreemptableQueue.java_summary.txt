**File Summary: `PreemptableQueue.java`**

**Overview**
----------------

The `PreemptableQueue` component, situated within the Resource Management/Scheduling layer of the YARN (Yet Another Resource Negotiator) Resource Manager Scheduler subsystem, manages preemptable resources and containers in a hierarchical queue structure.

**Key Responsibilities**
-----------------------------

* **Resource & Container Management**: Tracks and updates killable resources and containers across partitions, maintaining two core data structures:
	1. `totalKillableResources`: Partition-wise aggregate of killable resources.
	2. `killableContainers`: Partition-wise mapping of container IDs to `RMContainer` objects.
* **Hierarchical Queue Support**: Utilizes a `parent` reference to propagate changes to superior queues when adding or removing killable containers.

**Interfaces & Data Exchange**
-----------------------------------

* **Inputs**:
	+ `KillableContainer` objects (additions/removals)
	+ `partition` strings (for targeted resource/container lookups)
* **Outputs**:
	+ `Resource` objects (representing killable resources by partition)
	+ Mappings of container IDs to `RMContainer` objects (by partition)

**Dependencies & Integrations**
--------------------------------------

* **External Libraries**:
	+ `org.apache.hadoop.yarn.api.records` (YARN API records)
	+ `org.apache.hadoop.yarn.util.resource` (YARN resource utilities)
	+ `java.util` (Java utility classes)
* **Internal System Integrations**:
	+ **Recursive Parent Queue Notifications**: Notifies parent `PreemptableQueue` instances of changes.
	+ **Implicit Scheduler Integration**: Assumed to be utilized by the YARN Resource Manager Scheduler for informed resource management decisions.
