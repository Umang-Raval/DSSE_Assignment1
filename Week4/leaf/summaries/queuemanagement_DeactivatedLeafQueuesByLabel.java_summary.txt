**Queue Management Utility for Capacity Scheduler and YARN Resource Manager**

**Overview**
----------------

This Java-based utility plays a crucial role within the Capacity Scheduler subsystem of the YARN Resource Manager, specifically designed to manage the deactivation of leaf queues based on node labels. It provides essential functionality for tracking, calculating, and determining the activation of leaf queues within the constraints of available system capacity.

**Key Responsibilities**
-----------------------------

* **Tracking**: Monitors deactivation of leaf queues by node label.
* **Capacity Calculation**: Determines available capacity for activating new leaf queues.
* **Activation Guidance**: Offers methods to identify activatable leaf queues and their count.

**Core Functional APIs**
--------------------------------

* **`getTotalDeactivatedCapacity()`**: Returns the total deactivated capacity for a given node label by summing absolute capacities of deactivated leaf queues.
* **`canActivateLeafQueues()`**: Assesses whether available capacity suffices for a new leaf queue activation.
* **`getMaxLeavesToBeActivated(int)`**: Computes the maximum number of leaf queues activatable based on available capacity and pending application count.

**Data Exchange**
------------------

* **Inputs**:
	- `deactivatedLeafQueues` (Map): Deactivated leaf queues with capacities.
	- `parentQueuePath`, `nodeLabel` (Strings): Contextual identifiers.
	- Capacity values (`sumOfChildQueueActivatedCapacity`, `parentAbsoluteCapacity`, `leafQueueTemplateAbsoluteCapacity`).
	- `numPendingApps` (int): Pending application count.
* **Outputs**:
	- `totalDeactivatedCapacity` (float): Total deactivated capacity for a node label.
	- `availableCapacity` (float): Capacity available for new activations.
	- `Set<String>`: Names of deactivated leaf queues.

**Dependencies & Integrations**
--------------------------------------

* **Code Dependencies**:
	+ `org.apache.hadoop.yarn.server.resourcemanager.scheduler.capacity.QueueCapacities`
	+ `org.apache.hadoop.yarn.server.resourcemanager.scheduler.capacity.CSQueueUtils` (for `EPSILON` constant)
	+ `org.slf4j.Logger` (logging purposes)
* **Systemic Interactions**:
	+ **Capacity Scheduler**: Updates for capacity allocation post queue activity changes.
	+ **Resource Manager**: Reflects resource availability adjustments due to queue management.
	+ **Application Scheduler**: Informs about schedulable application limits based on available capacity.
